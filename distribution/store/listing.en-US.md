# PermissionScope

Suggested category: Utilities & tools. Pricing: Free, no trial, no in-app purchases. Markets: all supported markets subject to the publisher's legal review.

## Short description

See Windows file permissions, follow the evidence, and compare changes. Free, local, no account.

## Description

PermissionScope is a native Windows application for understanding file and folder permissions. Inspect the rules recorded by Windows, evaluate a selected Windows identity and follow the evidence behind its discretionary access.

Save local snapshots, compare observations, simulate removing a permission entry, and export HTML, PDF, Excel, CSV or JSON reports. The shared command-line engine supports administrative workflows. Optional daily scans use Windows Task Scheduler and your signed-in session.

Analysis and simulation are read-only. Applying a real change is a separate local-file operation with an exact-path confirmation, a saved observation, a durable rollback record and verification after writing.

Results remain Unknown when the necessary context is not established. Remote logon equivalence, DFS target discovery, complete inherited-ancestor tracing and central access policy are not certified by this release. Permission results do not guarantee successful file opening. Direct PDF export has script limitations; HTML printing is available for complex scripts.

No PermissionScope account, application telemetry, advertisements, subscriptions or paid tier. Local records and reports may contain account names and sensitive paths. Review them before sharing.
