## Short description

PermissionScope: native Windows permission analysis with inspectable evidence. Free forever, local, no account.

## Product introduction

PermissionScope helps explain Windows file permissions. It uses Windows Authz for discretionary decisions and keeps the supporting rules and group evidence visible. You can save snapshots, compare observations and simulate a permission-entry removal without changing the system.

It is free and local, with a shared CLI and report exports. This first release deliberately returns Unknown where remote or conditional context is not established. It is not a claim to solve every effective-access case in a domain.

The source, test corpus, limitations and release artifacts are available from the official project once published. Feedback with a small synthetic permission example is particularly useful.
