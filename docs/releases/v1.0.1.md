# PermissionScope 1.0.1

PermissionScope 1.0.1 consolidates the security, reliability, accessibility, packaging and public-site work completed after the first 1.0.0 publication.

## Highlights

- Stronger imported-snapshot validation before data reaches the UI, comparison or simulation paths.
- Integrity validation for NTFS and share security descriptors, with conservative `Unknown` behavior when Windows context is insufficient.
- Faster default directory-only scans and clearer enumeration failures.
- Website fixes for WebKit/mobile overflow, accessibility diagnostics, contrast, PWA identity/install metadata and offline caching.
- 72 refreshed native application captures with source/hash provenance enforced by CI.
- x64 and ARM64 packaging from the same source fingerprint.
- x64 silent install, installed CLI scan and uninstall smoke testing on a disposable Windows runner.
- Build provenance and CycloneDX SBOM attestations, plus SHA-256 checksums and a source archive.
- Release tooling now derives installer/package versions from the project version instead of hard-coded `1.0.0` paths.

## Distribution boundaries

Direct installers are currently unsigned. Windows may show reputation or publisher warnings until a trusted signing/Store identity is established. Verify downloads against `SHA256SUMS.txt` and the GitHub attestations.

ARM64 packages are cross-built in CI. This release does not claim physical ARM64 hardware certification.

Microsoft Store certification and WinGet availability are separate distribution milestones and are not implied by this GitHub Release.
