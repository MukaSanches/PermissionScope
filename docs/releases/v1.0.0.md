# PermissionScope 1.0.0

PermissionScope 1.0.0 is the first public release of a local-first Windows permission analysis tool built around a simple rule: show the answer, preserve uncertainty, and expose enough evidence for the user to inspect why Windows reached that result.

## Highlights

- Native Windows desktop application plus CLI.
- Windows Authz-backed discretionary access evaluation instead of a hand-written approximation of effective access.
- Four explicit result states: Granted, Partial, Denied and Unknown.
- Access Path evidence for contributing permission entries and recorded membership context.
- Local snapshots, comparison and in-memory permission simulation.
- Guarded remediation for ordinary local files with explicit confirmation, durable journal, verification and rollback.
- HTML, CSV, JSON, XLSX and PDF exports.
- Synthetic LAB demonstration with no real company or host identity data.
- x64 and ARM64 self-contained packages.
- Local-first operation with no PermissionScope account, required cloud service or application telemetry.
- Public security model, Trust Center, checksums, SBOM, source history and CI evidence.

## Safety model

PermissionScope does not convert missing context into a confident answer. Remote/S4U equivalence, conditional permission rules, unverified reparse targets and other contexts that cannot be proven safely remain `Unknown`.

Analysis and simulation are read-only. Applying a permission change is a separate workflow limited to supported ordinary local files and requires explicit confirmation. Directories, links and multi-link files are excluded from remediation.

## System requirements

- Windows 10 version 1809 or later.
- Use x64 for Intel/AMD Windows PCs.
- ARM64 packages are cross-built in CI. Physical ARM hardware certification is not claimed for this release.
- Complete packages include the required .NET runtime.

## Important boundaries

PermissionScope evaluates the Windows permission context it can establish; it does not claim to predict every possible file-open outcome. Integrity policy, encryption, file locks, administrative privilege effects, some remote/domain behaviors, DFS divergence and central access policy can be outside the available decision context.

Inherited ACE flags are preserved, but the exact ancestor/depth is not always established. Comparison does not calculate impact for every possible member of every changed group. Direct PDF export has script-shaping limitations documented in the release status; HTML plus browser Print to PDF is the fallback for complex scripts.
